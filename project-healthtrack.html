HealthTrack Analytics Platform

HealthTrack is a full-stack health monitoring system designed to help users track their wellness metrics and receive personalized recommendations. The platform features an automated backend and a user-friendly frontend for data visualization.

Problem

Managing and interpreting personal health data from multiple sources can be complex and overwhelming for individuals.

Solution

A unified platform that automates data entry, provides a clear health score, and generates personalized meal plans.

My Role

  • Full-stack development
  • Algorithm design
  • API integration

Technical Stack & Features

  • **Backend:** Architected a **Flask** backend with **Google Sheets API** integration, automating 80% of data entry.
  • **Data Visualization:** Developed a proprietary health scoring algorithm (92% accuracy) and visualized the data using **Chart.js**.
  • **API Integration:** Implemented the **Spoonacular API** to generate personalized and dynamic meal plans based on user data.

Outcome & Impact

HealthTrack provides a comprehensive solution for personal health management. This project demonstrates my proficiency in full-stack development, API integration, and creating impactful data-driven applications.
