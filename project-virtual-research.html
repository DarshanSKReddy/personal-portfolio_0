Virtual Research Assistant

This AI-powered academic tool was developed to streamline the research process. Mentored by Dr. Sowmya Venkatesh, this project leverages modern AI frameworks to automate time-consuming tasks like paper summarization and literature reviews.

Problem

Academic research is often a slow and manual process, requiring hours of reading and summarizing dense papers.

Solution

An intelligent tool that uses AI to quickly summarize papers and provide context-aware literature reviews, reducing research time by 60%.

My Role

  • Frontend and backend development
  • API integration and data pipeline design
  • Framework implementation

Technical Stack & Features

  • **Frontend:** Developed a user-friendly interface with **Streamlit**.
  • **AI/ML:** Integrated **GROQ API** with the **Autogen** framework for dynamic, context-aware responses.
  • **Data Source:** Implemented a pipeline using the ArXiv API to fetch the top 5 most relevant papers based on semantic similarity.

Outcome & Impact

The Virtual Research Assistant successfully demonstrated the power of AI to accelerate academic work. This project highlights my skills in AI/ML integration, API handling, and creating practical, user-centric applications.
